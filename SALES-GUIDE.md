## What to customize per client

1. Logo, site name, colors  
2. Categories for their city/district  
3. Weather city lat/lon in Settings  
4. Domain + Hostinger setup  
5. Admin training (30–45 min)  
6. Optional: extra reporters, custom pages  

## After client likes the demo

1. Create their hosting + domain  
2. Deploy fresh install (not the public demo DB)  
3. Set strong unique admin password  
4. Turn **Demo Mode OFF** on live client sites  
5. Upload their first e-news PDF + 5–10 sample posts  

## Important

- Public demo password is for selling only — never use it on a paid client live site.  
- Delete `/install` after every new deployment.  
- Keep demo content clean and professional before sending the link.
